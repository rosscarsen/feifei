# 原创合成试听素材

六段素材由 `tool/generate_sounds.py` 使用原创音符序列、数学振荡器和固定种子噪声生成，无外部歌曲或录音采样。

- 乐器：晨光木琴、星屑钟琴，各 16 秒。
- 自然：微风溪流 12 秒、水下气泡 8 秒，均为合成环境音。
- 生活：轻快脚步 4 秒、滴答时钟 8 秒，均为合成音效。

生成命令：使用安装 NumPy 的 Python 运行 `tool/generate_sounds.py`，并确保 FFmpeg 在 PATH 中。
应用打包 M4A；制作 WAV 写入 `build/audio-source`。技术时长与峰值见 manifest.json。
这些是试玩素材，不代表录音棚制作或第三方版权机构的权属认证。实际音色效果应在客户设备上试听确认。
